# 🎓 Student Management Project

A Java-based **Student Management System** developed using **Java Swing** that simplifies the management of student records through an intuitive desktop interface. This project demonstrates Object-Oriented Programming concepts, event-driven programming, and GUI development while providing essential student management functionalities.

---

## 📌 Features

- 👨‍🎓 Add New Students
- 📋 View Student Records
- ✏️ Update Student Information
- 🗑️ Delete Student Records
- 🔍 Search Students
- 📊 Student Details Management
- 🖥️ User-Friendly Java Swing Interface
- ⚡ Fast and Responsive Operations

---

## 🛠️ Tech Stack

- **Language:** Java
- **GUI Framework:** Java Swing
- **IDE:** IntelliJ IDEA / Eclipse / NetBeans
- **JDK:** Java 17+ (or compatible version)
